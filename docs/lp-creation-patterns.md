## 1. 核心：LPは「書く前」に決まっている 【逆算】

原典の制作フローは9工程あるが、**実際に文章を書く工程は6番目**である。それ以前の5工程はすべて準備に充てられている。

```
理念 → リサーチ → コンセプト → 構成 → ヘッドライン ─┬─ ここまで準備
                                                    │
                                              本文 ─┴─ ここで初めて書く
                                                    │
                                    クロージング → 画像LP変換 → 診断
```

この設計は、教材カリキュラムの章題とも一致する。

- LP基礎セミナー4章「**何のために売るのか**」 ↔ 理念GPTs「なぜ売るのか」を一行にする
- LP基礎セミナー5章「**良いLPは書く前に決まっている**」 ↔ 執筆前の4工程

つまりこの型の主張は「**文章力でLPを売るのではなく、書き始める前の設計でLPは売れる**」と読める。ライティングテクニックは9工程のうち3つ（ヘッドライン・本文・クロージング）にすぎない。

## 2. 制作フロー：9工程 【原典】

原典が「9つのGPTs」として分解している工程。カッコ内は原典の一行定義。

| # | 工程 | 原典の定義 | 完了条件（アウトプット） |
| --- | --- | --- | --- |
| 1 | **理念** | 「なぜ売るのか」を一行にする壁打ち相手 | 販売理由が一文で言い切れている |
| 2 | **リサーチ** | お客さんの悩みと生の言葉を掘る | 顧客の悩みが**顧客自身の語彙**で書き出されている |
| 3 | **コンセプト** | 「それ欲しい!!」の一行を作る | 提供価値が一行に圧縮されている |
| 4 | **構成** | LP全体の設計図を組む | セクションの並びと各セクションの役割が確定 |
| 5 | **ヘッドライン** | 最初の一行を量産する | 複数案から選定した第一行 |
| 6 | **本文** | あなたの言葉で本文を書き上げる | 各セクションの本文 |
| 7 | **クロージング** | 煽らずに背中を押す締めを作る | CTA直前の文章 |
| 8 | **画像LP変換** | 書いた文章を、ツールに入れる形に整える | 画像LP用に整形されたテキスト |
| 9 | **診断** | 完成したLPを、売れたLPの基準で辛口チェック | チェックリスト通過 |

### 工程ごとの補足 【逆算】

**1. 理念** — 「なぜ売るのか」を先に決める理由は、原典の10章にそのまま現れている。定価29,800円の根拠として「これからコンテンツ販売を始めたい人の手助けができたら」という理念を提示し、値下げを正当化している。理念は最後のCTAでも効く。

**2. リサーチ** — 「**生の言葉**」という限定が重要。分析者の要約語彙ではなく、顧客が実際に使う言葉を集めることが目的。原典のレビュー欄に出てくる「API登録で躓きました」「叩き台としては非常に秀逸」といった表現がまさにそれで、次のLPのコピー素材になる。

**3. コンセプト** — 「それ欲しい!!」の一行。原典自身のコンセプトは商品名に凝縮されている：**「はじめての」LPクリエイター**。「はじめての」という2語がターゲットと難易度と価格の全てを規定している。

**5. ヘッドライン** — 「**量産**する」と書かれている点。1本ひねり出すのではなく複数案を出して選ぶ工程として設計されている。原典のヘッドラインは `【1日で714部突破!!】歴10年のプロが発見した〝売れるLPの型〟` = **実績数値 + 権威年数 + ベネフィット**の3要素構成。

**7. クロージング** — 「**煽らずに**背中を押す」と明記されている。恐怖訴求や過度な煽りを型から外している。原典の実装は「50部ごとに2,000円ずつ値上げ」という事実提示のみで、「今すぐ買わないと損」とは書いていない。

## 3. LP構成テンプレート：13ブロック 【逆算】

原典の販売ページ自体（1〜13章）を構造として抽出したもの。**これは歴10年のプロが実際に714部売った実装例**であり、型の最良のサンプルとして扱える。

| # | ブロック | 役割 | 原典での実装 |
| --- | --- | --- | --- |
| 1 | **先出し特典** | 読む前に得をさせ、離脱を防ぐ | 「購入したら付いてくる」AI集客基礎講座 |
| 2 | **ターゲット宣言** | 自分ごと化。対象外の読者をここで降ろす | 「コンテンツ販売がしたい、LP制作代行をしたい方へ」 |
| 3 | **デモ** | 文章より先に現物を見せる | デモ動画 |
| 4 | **推薦者の声** | 第三者による権威づけ | 推薦画像4点 |
| 5 | **実績・事例** | 「自分の用途でも使えるか」に答える | サンプルLP7種（LINE登録 / メルマガ登録 / アニメ系 / スクール系 / 実店舗 / 販売 / 物販） |
| 6 | **作り手の専門性** | 商品ではなく人への信頼 | 「3つの分野の専門家たち」 |
| 7 | **ベネフィット** | 機能ではなく「手に入るもの」 | 「あなたが手に入れられるもの」 |
| 8 | **機能詳細** | 検討段階の読者を納得させる | ツール機能を7項目に分解（8-1〜8-7） |
| 9 | **追加特典** | 行動（レビュー）と引き換えの上乗せ | 100種類のデザインプロンプト |
| 10 | **価格** | 高い→安いの落差を作る | §5参照 |
| 11 | **想い** | 理念の再提示。感情での締め | 「最後に」 |
| 12 | **FAQ** | 反論処理 | 10問。§4参照 |
| 13 | **CTA** | 行動を一つに絞る | 特典受け取りフォーム登録 |

### 並び順の設計意図 【逆算】

- **特典（1）が価格（10）より前**：値段の話に入る前に「もらえるもの」を積んでおく
- **デモ（3）が説明（8）より前**：「どんなものか」を文章で説明するより現物を先に見せる
- **信頼（4・5・6）が価格（10）より前**：信頼が立つ前の価格提示は「高い」としか受け取られない
- **FAQ（12）がCTA（13）の直前**：最後の障害物を取り除いてから行動を促す
- **CTAは1つだけ**：原典の最終CTAは「フォーム登録」の一択（購入導線とは別）

## 4. FAQ = 反論処理の型 【原典 + 逆算】

原典のFAQ 10問を分類すると、6カテゴリの反論に対応している。**LPを書き終えたら、この6カテゴリが全部埋まっているか確認する。**

| カテゴリ | 読者の不安 | 原典の設問 |
| --- | --- | --- |
| **能力不安** | 自分に使いこなせるか | 「操作が苦手ですが初心者でも？」「スマホだけでも？」 |
| **コスト不安** | 追加でいくらかかるか | 「月額・サブスクは？」「ChatGPT有料プランは必要？」 |
| **適合性** | 自分のケースで使えるか | 「どんなジャンルのLPが作れる？」「何ページまで公開できる？」 |
| **成果不安** | 経験がなくても結果が出るか | 「文章も作れる？ライティング経験がなくても？」 |
| **利用条件** | 制約はないか | 「クライアントワークに使ってもいい？」 |
| **サポート** | 詰まったとき助けはあるか | 「購入後のサポートは？」 |
| **今買う理由** | 後回しにしてはいけないか | 「価格は今後変わりますか？」 |

### 回答の書き方のパターン 【逆算】

原典の回答には一貫した作法がある。

1. **結論を1語で先に出す** — 「A. はい。」「A. いいえ。」から始める
2. **不利な事実を隠さない** — コスト不安の回答で `**ただし、LPを生成する際に、AIのAPI利用料金が別途必要になります。（1LPあたり数百円）**` と太字で明示。都合の悪い情報を太字にすることで、他の回答の信頼性も上がる
3. **制約は回避策とセットにする** — 「ツール内では10ページまで」→「外部ツールを使用する場合は上限なし」

## 5. 価格提示の型 【原典】

原典の10章は3ステップで構成されている。

**ステップ1: 相場アンカーを積む**

> 同じようなLPツールを使おうと思えば、デザイン面だけで
> ・サブスク月額2万円
> ・安くても買い切り5万円
> 文章生成まで入れるとそれだけで追加で3万円〜5万円

先に「本来ならこの価格帯」を作る。

**ステップ2: 自社の妥当価格を提示してから、理念で下げる**

> 49,800円〜79,800円の販売価格が妥当かなと考えておりました。
> ただ、今回のツールの名前は〝はじめてのLPクリエイター〟です。
> （中略）という想いがあるので、**定価は29,800円にさせていただきました。**

値下げの理由を**理念に紐づける**のがポイント（→ §2 工程1）。「安売りしています」ではなく「こういう人を助けたいから、この価格にした」という構造。

**ステップ3: 段階値上げで先送りを潰す**

> **50部ごとに2,000円ずつ値上げさせていただきますのでぜひお早めに！**

煽り文句ではなく**ルールの提示**で希少性を作る（→ §2 工程7「煽らずに背中を押す」）。

なお実際の販売価格はリリース時 9,800円（FAQに記載）。レビュー3件の購入金額は ¥9,800 / ¥9,800 / ¥7,800 で、値上げ前の価格帯であることが確認できる。
