# AIオフィス

専任AI社員が所属するオフィス。社員は名前で呼べば、履歴書どおりに働きます。

## 社員名簿

| 社員番号 | 名前 | 役割 | 呼び出し | 履歴書 |
| --- | --- | --- | --- | --- |
| 001 | **ナギ（凪）** | SNS・ブログ用の整形 | 「ナギお願い」 | [resume.md](employees/nagi/resume.md) |

## 呼び出し方

社員の名前を呼ぶだけで、その社員が履歴書どおりに動きます。

```
ナギお願い
（ここに元原稿を貼る）
媒体: X単発 / Xスレッド / ブログ ...（省略時は既定セット）
```

## オフィスの構造

```
ai-office/
├── README.md              ← このファイル（社員名簿）
├── employees/
│   └── nagi/
│       └── resume.md      ← ナギの履歴書（手順・禁止事項の正典）
└── outputs/               ← 社員の成果物の保存先
                             命名: YYYY-MM-DD-<件名>.md

.claude/skills/
└── nagi/
    └── SKILL.md           ← ナギの出社届（これがあるから名前で呼べる）
```

履歴書を書き換えれば、その社員の働き方が変わります。
スキル側（`SKILL.md`）は履歴書を読みに行くだけなので、**触るのは履歴書だけで十分**です。

## 新しい社員を雇うとき

1. `ai-office/employees/<名前>/resume.md` に履歴書を書く
   - 名前 / 役割 / 手順 / やらないこと の4項目を必ず埋める
2. `.claude/skills/<名前>/SKILL.md` を作る
   - `description` に「◯◯お願い」など**呼び出しの言葉を必ず列挙する**（これがないと名前で呼んでも反応しません）
   - 本文は履歴書へのパスを示し、「まずこれを読め」と書く
3. このファイルの社員名簿に1行追加する

## 運用ルール

- 成果物は**チャットに貼る**＋`outputs/` に**ファイル保存**の両方で納品する
- 納品の最後には必ず**検収ポイントを3行以内**で添える
- 担当外の依頼が来たら、勝手に引き受けず「担当外」と伝える

## 引っ越しについて

このオフィスは現在 `Album` リポジトリに同居しています。
`ai-office/` と `.claude/skills/` の2つをそのままコピーすれば、専用リポジトリへ引っ越せます。
